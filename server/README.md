# 📻 วอภายใน (Demo)

> ดู `../README.md` สำหรับธีม 2 แบบ, แอป Android (ได้ยินเสียงแม้จอล็อก), วิธี build และการทดสอบ

เว็บแอปวอสื่อสารแบบกดค้างแล้วพูด ใช้คุยกันภายในองค์กร

## วิธีรัน
1. ติดตั้ง Node.js 18 ขึ้นไป
2. ในโฟลเดอร์นี้ พิมพ์คำสั่ง:
   ```
   npm install
   npm start
   ```
3. เปิด http://localhost:3000 บนคอมเครื่องนี้

## ใช้กับมือถือในวง Wi-Fi เดียวกัน
มือถือจะใช้ไมค์ได้เฉพาะผ่าน HTTPS เท่านั้น:
```
npm run cert      (ต้องมี openssl)
npm start
```
แล้วเปิด `https://<IP ของคอม>:3000` จากมือถือ (เซิร์ฟเวอร์จะพิมพ์ IP ให้ตอนเริ่ม)
มือถือจะเตือนว่าใบรับรองไม่ปลอดภัย ให้กด "ขั้นสูง" > "ดำเนินการต่อ" (ใบรับรองนี้สร้างเอง ใช้ได้แค่ในวงภายใน)

## ฟีเจอร์
- 4 ช่อง สลับช่องได้
- พูดได้ทีละคนต่อช่อง ถ้ามีคนพูดอยู่จะขึ้นว่า "ไม่ว่าง"
- แสดงคนออนไลน์ และไฮไลต์คนที่กำลังพูด
- เสียงบี๊บตอนเริ่ม/จบ (roger beep) และสั่นบนมือถือ
- พูดได้สูงสุด 60 วิต่อครั้ง เชื่อมใหม่อัตโนมัติเมื่อหลุด
- ประวัติการพูด, Spacebar = กดพูดบนคอม
- ธีมกลางคืน / ภาคสนาม (ปุ่มมุมขวาบน)
- ทดสอบโปรโตคอล: `npm test`

## โครงสร้าง
- `server.js` เซิร์ฟเวอร์ Node.js + WebSocket: จัดการช่อง สิทธิ์พูด และส่งต่อเสียง
- `public/index.html` หน้าแอป: อัดเสียงจากไมค์เป็น PCM 16 kHz แล้วส่งเป็นชิ้นเล็ก ๆ แบบเรียลไทม์

## ข้อจำกัดของเดโม
- ยังไม่มีระบบล็อกอินหรือรหัสผ่าน ใครเข้าเว็บได้ก็คุยได้
- เว็บ: ต้องเปิดหน้าเว็บค้างไว้ ถ้าจอล็อกหรือสลับแอป อาจไม่ได้ยินเสียง (ใช้แอป Android ในโฟลเดอร์ `../app` แทน)
- ไม่บันทึกเสียงย้อนหลัง
